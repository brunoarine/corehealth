# corehealth instructions for agents

`corehealth` is a small project to help the Brazilian MeshCore network to keep track of its health. 
It uses the SQLite database generated by CoreScope as the source of data, which is routinely updated and stored in db/meshcore.db.

For details on the database structure, consult the SCHEMA.md file.

If for some reason you need more details on the MeshCore packets structure, consult MESHCORE_PACKETS.md
